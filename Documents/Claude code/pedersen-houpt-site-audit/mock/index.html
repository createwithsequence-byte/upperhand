Pedersen & Houpt · website audit · design directions, built as pages

Five directions,
one brief.

The same two pages, built five ways. Same sentence, same six people, same matters, same attorney page for Eric J. Kordish, so the only thing that changes is the design. Each direction starts from an object in the firm's own world: a lobby directory, a deal announcement, the year 1957, a term sheet, the Loop. Attorney photographs are the firm's current headshots with the backdrops removed; the Chicago photographs are placeholders until the firm's own photo day.

What every direction must doSay who the firm is for in one sentence, show the people first, put dated proof above the fold, keep the wordmark and the red, put the client tools in the header, read on a phone in one thumb.
What changes between themThe idea, the typefaces, the color, the pictures, the layout rhythm, the motion, and what a first-time visitor feels in three seconds.
How to read themOpen each homepage, then its attorney page, on a laptop and on a phone. Ask which one a referred client would trust, which one a lateral would join, and which one the firm could live in for ten years.
